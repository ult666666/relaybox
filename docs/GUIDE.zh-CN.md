# RelayBox 中文指南

RelayBox 是一个本地 Webhook 收件箱示例，使用 Python 3.11+ 标准库和 SQLite。它展示签名校验、重复投递处理、事务领取、租约令牌、有限重试与死信恢复；不代表生产服务或真实客户使用。

## 快速运行

在项目目录执行：

```bash
python3 -m relaybox --db .local/demo.sqlite3 demo
python3 -m relaybox --db .local/demo.sqlite3 serve --demo-secret
```

访问 `http://127.0.0.1:8787`。演示仅含合成数据，四条记录分别处于排队、租约中、成功、死信状态。`demo` 不覆盖已有数据；再次体验请换一个数据库路径。`--demo-secret` 使用公开的合成演示密钥，不能用于真实数据。

在另一个终端运行 `python3 examples/send_webhook.py`，将同一签名投递发送两次。首次应返回 `202`，第二次返回 `200`。点击页面的 Refresh 查看新记录。

## 状态与恢复

- 相同 ID、相同原始内容摘要：返回已有记录，不新增任务；相同 ID、不同内容：返回 `409`。
- 每次领取都会增加尝试次数，并生成新的租约令牌。租约到期后，旧令牌不能确认或失败提交，即使尚未被其他工作者领取。
- 默认最多三次领取。失败后按 2、4 秒等退避，最大 60 秒；最终失败转入死信。过期最终租约在下一次领取时转为死信。
- 手动恢复：`python3 -m relaybox --db .local/demo.sqlite3 replay 3`。仅死信可恢复；恢复重置尝试次数并增加恢复计数。恢复次数由本地操作者控制。
- 控制台只读；工作者通过 CLI 或 Python API 操作，不提供远程工作者接口。

## 验证与边界

运行 `python3 -m unittest discover -v`。测试包括真实 HTTP 请求、多个 SQLite 连接并发领取、重复投递和旧工作者拒绝。

服务仅监听 IPv4 回环地址，采用明文 HTTP、单个 HMAC 密钥。请求上限 64 KiB，每次套接字读取超时 3 秒，同时处理最多 32 个连接。没有对外投递、账户权限、自动清理、备份或分布式扩展。任何能访问本地服务的进程都可能读取内容。租约令牌只保护此数据库，不能保证外部操作恰好执行一次。
